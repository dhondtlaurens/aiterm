# Contributing

AiTerm is built for its maintainer's own workflow. Bug reports are welcome; feature requests and
pull requests are not taken, and are closed with a pointer to this file.

## Reporting a bug

Use the
[bug report form](https://github.com/dhondtlaurens/aiterm/issues/new?template=bug_report.yml).
Include the AiTerm version (AiTerm › About AiTerm), your macOS and iTerm2 versions, and the
relevant lines of `~/Library/Application Support/AiTerm/aitermd.log` — remove anything private
first. AiTerm clears that log at every launch, so copy it before relaunching; when the sidebar says
"AiTerm’s helper keeps stopping", the log says why.

## Security

Do not open a public issue. Report it privately through
[GitHub's vulnerability reporting](https://github.com/dhondtlaurens/aiterm/security/advisories/new).

## Changing it yourself

AiTerm is GPL-3.0: you may build, change and share it under that licence. The README's
*Build from source* section has the commands.
