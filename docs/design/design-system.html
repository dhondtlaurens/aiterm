AiTerm Design System

Swift is the source of truth. The system is the code in app/Sources/AiTermUI/ and the rules in its README.md. There is no generated token file, no canvas and no build step.

This page is a human view of that code, synced on request by the design-system skill. When the two disagree, the Swift wins — and you never need this page to write correct Swift.

  1. Reuse before new. A new variant or content case on an existing primitive. Badge absorbed three bespoke types this way.
  2. A pattern — existing primitives arranged. It keeps an AiTerm name and lives in Views/, not in the library.
  3. A genuinely new primitive. It owes a standard name, every measurement from Metrics, every colour from Palette, a declared variant × state matrix, a line in the README's inventory, and a test under app/Tests/AiTermUITests/.

Colour

AiTerm is dark-only, so its greys are literal values rather than AppKit's semantic colours: a graphite ramp of grounds, three inks and two hairlines. Grounds rise from the well to the lightest control ground, and a field is drawn a step darker than what holds it while a button is a step lighter. Grounds are the same with or without Increase Contrast; the inks and hairlines resolve to a stronger value of their own under it, so a view needs to know nothing about the setting. The accent, the status colours and the link stay AppKit's; brand marks keep their vendor colours. A colour derived from another, a wash, a dimmed ink, a pressed state, is a named member too, never an .opacity(…) written in a view.

One more rule, enforced by PaletteDistinctionTests: every distinctly-written token must resolve to a distinct colour, in the dark appearance or under Increase Contrast. Where two roles share a value it is declared as an alias in the source, and shown as one here. The test exists because a hover wash once resolved to the surface it was painted over and drew a visible halo around every hovered avatar.

The greys are definitions; the accent family is resolved. Every ground, ink and hairline below is the literal the Swift writes. The accent, the status colours, the link and the placeholder are AppKit's own, read back under .darkAqua; the accent and everything derived from it follow the accent chosen in System Settings and are shown at the default blue. Where an ink or a hairline has an Increase Contrast value, it is given after IC.

Surface

A component reads the ground it sits on from the environment, @Environment(\.surface), set with .surface(_:), instead of taking a selected: Bool. Each case publishes its own ink, secondary ink, badge wash, hovered badge wash and occluding background, so a badge inside a newly selected row strengthens its wash by itself rather than every call site re-deriving the same colours. Selection is neutral: a selected row lifts its title to white and keeps every mark's colour, amber, green, the spinner, the done ring, a brand. Only .accent, a primary button's label, turns everything on it white. Surface is not a component and gets no card; it is a rule the components assume.

Scale

Every number on this page is a size at ×1. It becomes points where a view reads it, at the environment's InterfaceScale — @Environment(\.interfaceScale), set with .interfaceScale(_:), like Surface. Typography scales by itself, because View.font(TypeStyle) reads the environment, and is not rounded, so text never outgrows the layout around it. Space, Radius and Size are read through scale(…) and land on whole points; at ×1 that is the identity. Strokes — hairlines, borders, rings, the focus ring — do not scale. A size: parameter is points on screen: the caller scales the token it passes, and a view scales only its own token reads.

Typography

The macOS system text scale. AiTerm draws with .system(size:) rather than a text style, so each member is labelled below with the system style it is the size of. A TypeStyle keeps its size, weight and design as separate parts, and its nsFont consults all three — so the handful of AppKit views that take an NSFont can never quietly narrow a style to just its size. A style's .tabular variant sets tabular figures (.monospacedDigit()) in the same face, so a count, a time or a percentage keeps its width as it changes: the system face is for words and numbers, the monospaced face for code alone. Specimens are set at their real size, weight and design.

One theme

AiTerm is dark-only. There is no light variant to keep in sync, and this page commits to the same single theme rather than inventing one the app does not have. Kerning and shadow geometry — blur radius, offset, opacity — are deliberately not tokenised: they are one-off optical corrections on a single element, not a scale anything else draws from. Their absence from Metrics is a decision, not an oversight.

States are a matrix

A component's states are declared up front, not discovered: default, hover, pressed, disabled, focused, selected. A new primitive owes that matrix the same way it owes a name — every variant crossed with every state, decided before the first call site, rather than a hover wash bolted on the week someone notices it is missing.

One rule overrides the matrix: when a target does not exist, the control is absent, not disabled. SidebarView draws no VS Code badge when VS Code is not installed, rather than a greyed one — the branch after it stays on the row as plain text. A disabled control is a promise that the action exists and is currently unavailable — if it can never become available, showing it is a lie the user has to test by clicking.

Reduce Motion is honoured rather than ignored: StatusMark keeps its arc and drops the rotation.

Select

AiTermUI/Select.swift

A task or terminal row whose agent ended its turn with work still running — a test run, a dev server, a monitor, from Claude's background_tasks — is TaskStatus.background: working outranks it, it outranks done, and it is not yours to act on, so no Focus View, no Dock badge, and a collapsed header counts it with working. The Operator

One Operator and one broadcast at a time. The broadcast runs a sprint's tickets: the Operator plans, starts the tasks, steers its agents and answers them from the brief and the code, and AiTerm does every write it asks for, gated by the slices frozen in the broadcast. Everything it says is one OperatorBadge; anything amber is yours. Two Metrics members are its own, Size.inlineMark and Sheet.boardHeight; no Palette member: the needs-you badge and a question's amber edge reuse statusChipAttentionFill and statusChipAttentionStroke.
