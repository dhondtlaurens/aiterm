# Operator signals

End any running broadcast in the installed AiTerm before updating.

Signals watch Jira, GitLab or GitHub and start or continue a task when an item matches. One Operator
works with the Oracle, asks you in its own chat when needed, and follows each task to its chosen
done condition. Workers can publish their own branch and draft request; automatic merging needs
an explicit choice on the signal.

Broadcasts and their boards are removed. Their tasks and archived tasks become ordinary tasks;
worktrees, branches and saved conversations stay. The next workspace save drops the retired
broadcast records. Configure new signals to automate future work.
